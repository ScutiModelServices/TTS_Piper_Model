# Purpose

**Kind:** text → audio

**Group:** Text-to-Speech

**Tags:** `cpu`, `streaming`

| | |
|---|---|
| Input | Plain text (1–5000 chars), voice name, speed (0.5–2). |
| Output | WAV file (16-bit mono), streamable sentence by sentence. |
| Runs on | CPU (onnxruntime). No GPU. |

**Use for:** fast, light English speech. Default fast voice.
**Not for:** voice cloning, high expressiveness.
